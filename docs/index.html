[编辑]作品一览¶

青梅竹马失踪后变成电飞鼠这档事

合众地区·飞云市。超能力引发的「宝可梦化事件」把一批人类变成了宝可梦，他们不得不以新的身体继续生活。

想要飞的始祖小鸟

菲洛若亚大陆的北方。从繁盛村出发，一路经过繁盛之森、沃雷奥斯岛、盐风镇……目前以地点与世界观设定为主。

[编辑]从哪儿读起¶

  • 第一次来：先看 宝可梦化事件，那是《幼失鼠》整个系列的起点。
  • 想认人：从 上鹈 开始，她是第一季的视角人物。
  • 想逛地图：菲洛若亚大陆 上有那张手绘地图。

[编辑]这个维基怎么用¶

  • 左侧导航：按作品和分类展开，带条目数量。
  • 顶部搜索：输入角色名、地名或任意关键字，会即时给出候选。
  • 🔒 折叠段落：涉及第二季及以后的剧情默认收起，点开才显示；展开状态会记住。
  • 每个条目右上角：有「编辑 / 历史」按钮，直接跳到 GitHub 上对应的 Markdown 源文件。
  • 右下角分类条：点分类名可以看到同类条目。
