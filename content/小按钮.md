## 本站按钮

![[见远观星集.png]]

直接复制这段贴到你自己的页面里就行：

```html
<a href="https://flygon611.github.io/Wiki_for_flygonish/">
  <img src="https://flygon611.github.io/Wiki_for_flygonish/assets/buttons/见远观星集.png"
       width="88" height="31" alt="见远观星集">
</a>
```

想在别处用普通尺寸的大图，用这张（1200×630，链接卡片也是它）：

```html
<img src="https://flygon611.github.io/Wiki_for_flygonish/assets/og-cover.png" width="600" alt="见远观星集">
```

## 「任何瀏覽器適用」按钮

![[anybrowser-abchinese.gif]]

这张不是我们画的，来自 **Viewable with Any Browser 运动**（<http://anybrowser.org/campaign/>）。
该站作者 Cari D. Burstein 明确写了：**欢迎把图形复制到自己的站点使用**，只希望链回说明页、别直接热链别人的服务器。

我们的用法符合这个要求：图片复制到了本站 `assets/buttons/`，页脚的按钮也链回了那一页。所以保留署名即可，不需要额外申请。

## 想自己找素材的话，这几个源我查过

| 来源 | 有什么 | 授权 |
| --- | --- | --- |
| [Viewable with Any Browser](http://anybrowser.org/campaign/abgraphics.html) | 662 张按钮图（含中文、无文字底图），整包可下 | **作者明确允许复制**，要求链回、别热链 |
| [GifCities](https://gifcities.org/)（Internet Archive） | GeoCities 时代的动图搜索：闪光、分割线、NEW!、各种小图标 | ⚠️ 归档的个人主页 GIF，**原始版权归属不明**。个人怀旧站常见用法，但不是干净授权，商用别碰 |
| [Wikimedia Commons：Under construction signs](https://commons.wikimedia.org/wiki/Category:Under_construction_signs) | 「施工中」标志 | 多为公有领域（简单图形/文字不受版权保护），逐张确认 |
| [Kenney 1-Bit Pack](https://kenney-assets.itch.io/1-bit-pack) | 像素风图标集 | **CC0**，随便用不用署名 |
| Google Fonts 的像素字体 | Press Start 2P / Silkscreen / VT323 | **OFL**，可内嵌到网页 |
| [ktwrd/88x31](https://github.com/ktwrd/88x31) | 88×31 按钮合集 | ❌ **没有任何授权声明**，只能看，不要打包进自己的站 |

一句话原则：**能自己画的就自己画**（上面 `make_buttons.py` 就是干这个的），要用别人的就优先挑明确写了 CC0 / OFL / 作者授权的。
GifCities 那种「怀旧素材」虽然好看，但它是从别人的个人主页里归档来的，放自己玩的页面上属于灰色地带，别用在正经项目里。

## 顺便说一句：网页缩略图

浏览器标签页的小图标是 `assets/favicon.png`（博客那张像素标），链接卡片用的是 `assets/og-cover.png`（头图裁的 1200×630）。
要换的话，替换这两个文件、或者改 `wiki.config.json` 里的 `icon` / `og_image` 就行。
